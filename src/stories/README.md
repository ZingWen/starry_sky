# 每日驚喜劇情

一個檔案就是一個劇情。放進這個資料夾就會自動加入隨機。

## 新增劇情

複製 `_template.js`，改成不含底線開頭的檔名（例如 `my-story.js`），並把 `id` 改成不重複的名稱。

## 步驟

| 寫法 | 作用 |
|---|---|
| `say('畫面文字')` | 顯示並朗讀畫面文字，只有 `...` 的句子不唸 |
| `say('畫面文字', 'Read aloud')` | 顯示中文，朗讀第二個參數 |
| `say('畫面文字', '')` | 這句不朗讀 |
| `say('畫面文字', undefined, 'tua-18/001.mp3')` | 播放 `public/voices/tua-18/001.mp3`，優先於朗讀 |
| `ask(option('按鈕', [ ...台詞 ]), ...)` | 選項，最多 3 個，必須緊接在一句 `say` 後面 |
| `waitForSilence(say('關掉了嗎？'))` | 顯示這句話，等使用者把聲音關掉、連續無聲後才繼續 |

選項裡的台詞播完後，會自動接回 `ask` 的下一步，所以共同結尾寫在 `ask` 後面就好。如果選項後面什麼都沒有，對話就結束。

選了不用回應時可以寫 `option('按鈕', [])`。想換行就在文字裡加 `\n`。

## 測試

- 網址加上 `?surprise`，重新整理後點一下畫面就會出現；指定劇情用 `?surprise=劇情id`。
- `npm run dev` 時會檢查劇情，寫錯會在瀏覽器主控台顯示 `[劇情錯誤]`。

語音、語速、音高在 `_settings.js`。
